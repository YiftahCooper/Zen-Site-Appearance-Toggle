# BBC Sport appearance observation

Reported page: https://www.bbc.com/sport/rugby-union/articles/cr89j91lqlvqo

Inspected on 4 October 2026 in a separate Codex in-app browser tab. No everyday Zen profile was accessed, and no website settings were changed. This is source/current-rendering evidence, not a native SAT Light/Dark comparison.

The article loaded normally. All six document stylesheets were readable (35, 561, 57, 33, 106 and 3 top-level rules). Recursive rule inspection found no `prefers-color-scheme`, `color-scheme`, dark-mode or `[data-theme` match. The page had an unconditional `body { background-color: rgb(248, 248, 248); }` rule. Its current body background was that light grey, with heading text `rgb(24, 24, 24)`. The browser reported a Light preference during this observation. No appearance/theme control was present among the page's buttons, selects or inputs.

This supports the hypothesis that this particular Sport article does not supply a native dark stylesheet for SAT to select. It does not establish behavior under a Dark preference, every BBC product's behavior, account-dependent behavior or a confirmed live-Zen root cause. JavaScript could theoretically install different styles under another condition; that path was not exercised here.

SAT sends a native per-tab colour-scheme preference. Its additional website setup currently covers Google and Gemini. Creating a dark presentation for a site without a corresponding design would require an optional recolouring/style feature; it is not equivalent to changing an ignored account setting. No speculative BBC CSS was added to the tested 1.3.0 package.

Version 1.3.0 was published separately at commit `8435fbc6be34dc86fc7ea15d74b48dc3ae1e8934`. This observation is not a claim that BBC was fixed in that release.
